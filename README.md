# AIClinic DICOM Web Viewer

A web-based DICOM viewer application built with React that allows users to upload and view DICOM files, including ECG data visualization.

## Features

- DICOM file upload
- DICOM image viewing
- ECG data visualization
- Modern and responsive UI

## Setup

1. Install dependencies:
```bash
npm install
```

2. Start the development server:
```bash
npm start
```

The application will be available at http://localhost:3000

## Technologies

- React
- ECG DICOM Web Viewer
- Material-UI
- DICOM.js
